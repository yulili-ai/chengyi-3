# 登录后端验证步骤

1. 在项目目录启动服务：`cd server && .venv/bin/python scripts/launch_shared.py --no-browser`
2. 打开开发接口文档：`http://127.0.0.1:8000/docs`
3. 调用账号验证码申请接口，填写任意有效邮箱。
4. 开发环境响应中的 `development_code` 是本次验证码。
5. 调用验证码验证接口填写邮箱和验证码；保存响应中的 `access_token`。
6. 调用“读取当前账号”接口，在请求头填写：
   `Authorization: Bearer <access_token>`
7. 调用“账号作品列表”接口；未迁移作品时列表为空，迁移作品后应显示作品。
